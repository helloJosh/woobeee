# Game Plan 4 — Front (Tabs, Game Screens, My Page) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A visitor lands on the home page, opens the game hub, creates an omok or dodge room, shares the invite link, and plays; a member opens My Page and sees their profile, their record, and a replay they can watch.

**Architecture:** One socket client module owns reconnection and `seq` bookkeeping; screens only subscribe to typed events. The dodge replay viewer re-runs the same tick loop as the server, ported to TypeScript from the spec — so the port lives in one file with its own tests, not scattered through a component.

**Tech Stack:** Next.js 14 App Router, React 18, TypeScript, Tailwind, shadcn/ui, native `WebSocket`.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-08-01-game-omok-dodge-design.md`
- Prerequisite: **Plans 1–3 complete.** The backend endpoints and the `/ws/game` protocol must exist.
- **Top tabs are exactly three:** 홈 / 기술블로그 / 마이페이지. The game hub is reached from the home CTA, not from a fourth tab.
- Routes: `/` landing, `/blog` existing, `/mypage`, `/game`, `/game/omok/[roomId]`, `/game/dodge/[roomId]`.
- **WebSocket does not go through Next.js rewrites.** Rewrites proxy HTTP only; the socket connects straight to the WebFlux origin via `NEXT_PUBLIC_WS_BASE_URL`.
- The board fills the available height on desktop with a fixed-width sidebar to its right; on narrow screens the board stacks above the sidebar.
- Do not touch `app/products`, `app/cart`, `app/chat` beyond removing links to them. Deleting those pages is a separate task.
- Verification for every task: `cd front && npm run build && npx tsc --noEmit`. `next.config.mjs` sets `typescript.ignoreBuildErrors`, so **`npm run build` alone does not typecheck** — always run `tsc` too.
- Every task ends with a commit.

```ts
 * WebSocket 은 Next.js rewrites 를 타지 않는다 — rewrites 는 HTTP 만 프록시한다.
 * 그래서 소켓만 WebFlux 오리진으로 직접 붙는다.

const DEFAULT_WS_BASE_URL = "ws://localhost:8001"

export function gameSocketUrl(): string {
    const configured = process.env.NEXT_PUBLIC_WS_BASE_URL?.trim()
    if (configured) {
        return `${configured.replace(/\/$/, "")}/ws/game`
    }

    // 같은 오리진으로 폴백하면 소켓이 Next 로 가고, Next 는 업그레이드를 못 하므로
    // 반드시 실패한다. 그래서 브라우저에서도 개발 기본값을 쓰고, 대신 이유를 남긴다.
    if (typeof window !== "undefined") {
        console.warn(
            `NEXT_PUBLIC_WS_BASE_URL 미설정 — 개발 기본값 ${DEFAULT_WS_BASE_URL} 을 쓴다. ` +
                "배포 환경이라면 WebFlux 오리진을 지정해야 한다."
        )

    return `${DEFAULT_WS_BASE_URL}/ws/game`
```

Reconnection uses exponential backoff capped at five attempts. Every reconnect re-sends `JOIN` — the server treats a known `participantId` as a reconnection, so this is exactly the resume path Plan 1 built.

- [ ] **Step 1: Write `front/lib/game-socket.ts`**

```ts
"use client"

import { gameSocketUrl } from "@/lib/game-config"

export type SocketStatus = "connecting" | "open" | "reconnecting" | "closed"

export interface ServerMessage {
    type: string
    ackSeq?: number
    payload?: any
}

export interface GameSocketOptions {
    roomId: string
    inviteCode: string
    token: string
    onMessage: (message: ServerMessage) => void
    onStatusChange?: (status: SocketStatus) => void
}

export interface GameSocket {
    send: (type: string, payload?: unknown) => number
    close: () => void
}

const MAX_RETRIES = 5
const BASE_DELAY_MS = 500

export function createGameSocket(options: GameSocketOptions): GameSocket {
    let socket: WebSocket | null = null
    let seq = 0
    let retries = 0
    let closedByCaller = false
    let retryTimer: number | undefined

    const setStatus = (status: SocketStatus) => options.onStatusChange?.(status)

    const open = () => {
        setStatus(retries === 0 ? "connecting" : "reconnecting")
        socket = new WebSocket(gameSocketUrl())

        socket.onopen = () => {
            retries = 0
            setStatus("open")
            // 재접속도 JOIN 이다. 서버는 이미 아는 participantId 면 자리를 잇는다.
            send("JOIN", {
                roomId: options.roomId,
                inviteCode: options.inviteCode,
                token: options.token,
            })
        }

        socket.onmessage = (event) => {
            try {
                options.onMessage(JSON.parse(event.data) as ServerMessage)
            } catch {
                // 서버가 보낸 것이 JSON 이 아니면 무시한다. 소켓을 끊을 이유는 없다.
            }
        }

        socket.onclose = () => {
            if (closedByCaller) {
                setStatus("closed")
                return
            }

            if (retries >= MAX_RETRIES) {
                setStatus("closed")
                return
            }

            const delay = BASE_DELAY_MS * 2 ** retries
            retries += 1
            setStatus("reconnecting")
            retryTimer = window.setTimeout(open, delay)
        }

        socket.onerror = () => {
            socket?.close()
        }
    }

    const send = (type: string, payload?: unknown): number => {
        seq += 1
        if (socket?.readyState === WebSocket.OPEN) {
            socket.send(JSON.stringify({ type, seq, payload: payload ?? {} }))
        }
        return seq
    }

    open()

    return {
        send,
        close: () => {
            closedByCaller = true
            if (retryTimer !== undefined) {
                window.clearTimeout(retryTimer)
            }
            socket?.close()
        },
    }
}
```

> 위 블록은 **실제로 반영된 것보다 약하다**. Task 3 리뷰가 다섯 가지를 고쳤고
> (`payload?: any` -> `unknown` + `isServerMessage`, `SocketStatus` 에 `joined`/`rejected` 추가,
> `onopen` 의 `retries = 0` 제거, 토큰을 매 재접속마다 다시 읽기, 버린 소켓의 핸들러 detach),
> Task 3B 가 `GAME_SNAPSHOT` 을, Task 3C 가 그 페이로드 타입을 더했다. Task 6B 는 `ErrorPayload`
> 의 `code` 를 숫자 상태에서 `game_*` 문자열로 바꾸고(숫자는 `status`), `onStatusChange` 에
> 거절 사유 코드를 싣는 두 번째 인자를 더했다. 단일 출처는 이제 `front/lib/game-socket.ts` 다 —
> 이 블록을 그 파일에 다시 덮어쓰지 말 것.

```tsx
import type { GameType, RoomSummary } from "@/lib/types"

interface RoomJoinGateProps {
    roomId: string
    inviteCode: string
    expectedGameType: GameType
    onReady: (token: string) => void
}

export default function RoomJoinGate({
    roomId,
    inviteCode,
    expectedGameType,
    onReady,
}: RoomJoinGateProps) {
    const { loading, isAuthenticated } = useAuth()
    const [summary, setSummary] = useState<RoomSummary | null>(null)
    const [error, setError] = useState<string | null>(null)
    const [nickname, setNickname] = useState("")
    const [joining, setJoining] = useState(false)

    useEffect(() => {
        if (!inviteCode) {
            setError("초대 코드가 없는 링크입니다.")
            return
        }

        gameAPI
            .getRoomSummary(roomId, inviteCode)
            .then(setSummary)
            .catch((cause) => setError(cause instanceof Error ? cause.message : "방을 찾을 수 없습니다."))
    }, [roomId, inviteCode])

    // 로그인 상태면 회원 access token 을 그대로 쓴다.
    useEffect(() => {
        if (loading || !summary || !isAuthenticated) {
            return
        }
        const token = tokenManager.getToken()
        if (token) {
            onReady(token)
        }
    }, [loading, summary, isAuthenticated, onReady])

    const joinAsGuest = async () => {
        setJoining(true)
        setError(null)
        try {
            const guest = await gameAPI.issueGuestToken(roomId, inviteCode, nickname.trim())
            onReady(guest.token)
        } catch (cause) {
            setError(cause instanceof Error ? cause.message : "참가하지 못했습니다.")
            setJoining(false)
        }
    }

    if (error) {
        return (
            <div className="mx-auto max-w-md space-y-4 py-20 text-center">
                <p className="text-sm text-destructive">{error}</p>
                <Button asChild variant="outline">
                    <Link href="/game">게임 목록으로</Link>
                </Button>
            </div>
        )
    }

    if (loading || !summary) {
        return (
            <div className="flex min-h-[50vh] items-center justify-center">
                <Loader2 className="h-6 w-6 animate-spin text-muted-foreground" />
            </div>
        )
    }

    if (summary.gameType !== expectedGameType) {
        return (
            <div className="mx-auto max-w-md space-y-4 py-20 text-center">
                <p className="text-sm text-destructive">이 링크는 다른 게임의 방입니다.</p>
                <Button asChild variant="outline">
                    <Link href="/game">게임 목록으로</Link>
                </Button>
            </div>
        )
    }

    return (
        <div className="mx-auto max-w-md space-y-6 py-20">
            <div className="space-y-1 text-center">
                <h1 className="text-2xl font-semibold">
                    {summary.gameType === "OMOK" ? "오목" : "장애물피하기"} 방에 참가
                </h1>
                <p className="text-sm text-muted-foreground">
                    {summary.participantCount} / {summary.capacity}명
                    {summary.status !== "WAITING" ? " · 이미 시작된 게임입니다" : ""}
                </p>
            </div>

            <div className="space-y-3">
                <Button asChild className="w-full" variant="outline">
                    <Link href="/login">로그인하고 참가</Link>
                </Button>

                <div className="relative py-2 text-center text-xs uppercase text-muted-foreground">또는</div>

                <Input
                    value={nickname}
                    onChange={(event) => setNickname(event.target.value)}
                    placeholder="닉네임 (필수)"
                    maxLength={20}
                />
                <Button
                    className="w-full"
                    disabled={joining || nickname.trim().length === 0}
                    onClick={joinAsGuest}
                >
                    {joining ? <Loader2 className="mr-2 h-4 w-4 animate-spin" /> : null}
                    닉네임으로 참가
                </Button>

}
```

```ts
/**

 */

/**
 * app-webflux 의 `RoomService.MIN_PLAYERS`(2)와 같은 값이다. 여기서 값을 바꿔도 서버 판정은
 * 그대로이므로, 바꾸려면 RoomService 를 먼저 고친다.
 */
export const MIN_ROOM_PLAYERS_TO_START = 2

/** 소유자 표시(왕관 아이콘)와 "게임 시작" 버튼 노출 여부가 같이 쓰는 판단. */
export function isRoomHost(selfParticipantId: string | null, hostParticipantId: string): boolean {
    return selfParticipantId !== null && selfParticipantId === hostParticipantId
}

/**
 * `Room.beginGame(String, int)` 의 인원·준비 조건과 같다 — `members.size() >= minPlayers`
 * 그리고 `members.values().stream().allMatch(RoomMember::ready)`(방장 포함 전원). 정원 일치
 * (오목 2인 고정)나 방장 여부, 방 상태(WAITING)는 서버가 최종 판정하므로 여기서 다시 걸지
 * 않는다 — 이 함수가 참이어도 서버가 `NOT_ALL_READY`/`NOT_HOST` 등으로 거절할 수 있고, 그건
 * 정상이다. 이 값은 그 결과를 미리 보여주는 것뿐이지, 서버를 대신하는 것이 아니다. 느슨하게
 * (예: 전원 대신 정원만 채우면 된다고) 바꾸면 버튼은 활성화된 채 서버만 계속 거절하는 어긋난
 * 화면이 된다.
 */
export function canStartRoom(participants: ParticipantView[]): boolean {
    return (
        participants.length >= MIN_ROOM_PLAYERS_TO_START && participants.every((participant) => participant.ready)
    )
}

/**
 * 초대 링크 복사. post-detail.tsx 의 handleShare/fallbackCopy 와 같은 이유로 두 경로를 둔다 —
 * 비보안 컨텍스트(HTTP)나 Clipboard API 가 없는 브라우저에서 `navigator.clipboard.writeText`
 * 는 예외를 던지는데, 그걸 그대로 두면 클릭 핸들러 밖에서 unhandled rejection 이 나고 버튼은
 * 눌러도 아무 반응이 없다. 성공 여부를 boolean 으로 돌려주고, 복사 완료 표시(체크 아이콘)는
 * 호출부가 그 값을 보고 켠다.
 */
export async function copyTextToClipboard(text: string): Promise<boolean> {
    if (typeof window !== "undefined" && navigator.clipboard && window.isSecureContext) {
        try {
            await navigator.clipboard.writeText(text)
            return true
        } catch (error) {
            console.error("clipboard.writeText 실패:", error)
        }
    }
    return fallbackCopyToClipboard(text)
}

function fallbackCopyToClipboard(text: string): boolean {
    if (typeof document === "undefined") {
        return false
    }
    const textarea = document.createElement("textarea")
    textarea.value = text
    textarea.style.position = "fixed"
    textarea.style.left = "-9999px"
    document.body.appendChild(textarea)
    textarea.select()
    try {
        return document.execCommand("copy")
    } catch (error) {
        console.error("execCommand copy 실패:", error)
        return false
    } finally {
        document.body.removeChild(textarea)
    }
}
```

```tsx
"use client"

import { useCallback, useEffect, useMemo, useRef, useState } from "react"
import { useParams, useSearchParams } from "next/navigation"
import OmokBoard, { type OmokPlacement } from "@/components/game/omok-board"
import RoomJoinGate from "@/components/game/room-join-gate"
import RoomSidebar from "@/components/game/room-sidebar"
import {
    createGameSocket,
    isServerMessage,
    type GameEndPayload,
    type GameSocket,
    type ServerMessage,
} from "@/lib/game-socket"
import { getFriendlyErrorMessage } from "@/lib/errors/error-utils"
import type { ParticipantView, RoomStatus } from "@/lib/types"

const BOARD_SIZE = 15

export default function OmokRoomPage() {
    const params = useParams<{ roomId: string }>()
    const searchParams = useSearchParams()
    const roomId = params.roomId
    const inviteCode = searchParams.get("invite") ?? ""

    const [token, setToken] = useState<string | null>(null)
    const [participants, setParticipants] = useState<ParticipantView[]>([])
    const [hostParticipantId, setHostParticipantId] = useState("")
    const [status, setStatus] = useState<RoomStatus>("WAITING")
    const [placements, setPlacements] = useState<OmokPlacement[]>([])
    const [turnParticipantId, setTurnParticipantId] = useState<string | null>(null)
    const [turnDeadline, setTurnDeadline] = useState<string | null>(null)
    const [selfParticipantId, setSelfParticipantId] = useState<string | null>(null)
    const [notice, setNotice] = useState<string | null>(null)

    const socketRef = useRef<GameSocket | null>(null)

    const inviteUrl = useMemo(() => {
        if (typeof window === "undefined") {
            return ""
        }
        return `${window.location.origin}/game/omok/${roomId}?invite=${inviteCode}`
    }, [roomId, inviteCode])

    // payload 는 unknown 이다. isServerMessage 로 좁히는 것이 그것을 읽는 유일한 방법이다 —
    // switch (message.type) 로는 좁혀지지 않는다(아래 노트 참조).
    const handleMessage = useCallback((message: ServerMessage) => {
        if (isServerMessage(message, "ROOM_STATE")) {
            setParticipants(message.payload.participants)
            setHostParticipantId(message.payload.hostParticipantId)
            setStatus(message.payload.status)
            return
        }

        if (isServerMessage(message, "GAME_START")) {
            setStatus("IN_PROGRESS")
            setNotice(null)
            return
        }

        // 재접속 경로. ROOM_STATE 바로 뒤에 서버가 판 전체를 다시 보내 준다.
        // 통째로 갈아 끼운다 — 끊긴 동안 놓친 수가 있으므로 지금 판에 이어 붙이면 어긋난다.
        if (isServerMessage(message, "GAME_SNAPSHOT")) {
            const snapshot = message.payload
            // 방의 게임 종류는 고정이라 실제로는 항상 OMOK 이지만, 이 분기가 없으면
            // 타입이 moves 를 읽게 해 주지 않는다. 그게 이 유니온의 목적이다.
            if (snapshot.gameType !== "OMOK") {
                return
            }
            setPlacements(snapshot.moves.map(({ x, y, color }) => ({ x, y, color })))
            setTurnParticipantId(snapshot.nextTurn)
            setTurnDeadline(snapshot.turnDeadline)
            setNotice(null)
            return
        }

        if (isServerMessage(message, "OMOK_MOVED")) {
            const move = message.payload
            setPlacements((current) => [...current, { x: move.x, y: move.y, color: move.color }])
            // 승리 착수에는 nextTurn·turnDeadline 이 아예 오지 않는다. 이 분기를 빼면
            // 판은 끝났는데 차례 표시만 살아 있는 화면이 된다.
            if (move.nextTurn === undefined) {
                setTurnParticipantId(null)
                setTurnDeadline(null)
            } else {
                setTurnParticipantId(move.nextTurn)
                setTurnDeadline(move.turnDeadline)
            }
            setNotice(null)
            return
        }

        if (isServerMessage(message, "OMOK_REJECTED")) {
            setNotice(rejectionText(message.payload.reason))
            return
        }

        if (isServerMessage(message, "GAME_END")) {
            setStatus("FINISHED")
            setTurnParticipantId(null)
            setTurnDeadline(null)
            setNotice(`게임 종료 — 승자 ${winnerName(message.payload)}`)
            return
        }

        if (isServerMessage(message, "ERROR")) {
            // payload.message 는 서버 로그용 영어다. 사용자에게 보여줄 문구는 payload.code
            // (`game_*`)로 error-messages.ts 에서 찾는다 — HTTP 실패와 같은 지도다.
            setNotice(getFriendlyErrorMessage(message.payload.code))
        }
    }, [])

    useEffect(() => {
        if (!token) {
            return
        }

        const socket = createGameSocket({
            roomId,
            inviteCode,
            token,
            onMessage: handleMessage,
        })
        socketRef.current = socket

        return () => {
            socket.close()
            socketRef.current = null
        }
    }, [token, roomId, inviteCode, handleMessage])

    // 내 participantId 는 서버가 따로 알려주지 않는다. 첫 ROOM_STATE 이후,
    // 아직 모른다면 목록에서 마지막에 들어온 사람을 나로 본다.
    useEffect(() => {
        if (selfParticipantId || participants.length === 0) {
            return
        }
        setSelfParticipantId(participants[participants.length - 1].participantId)
    }, [participants, selfParticipantId])

    if (!token) {
        return (
            <RoomJoinGate
                roomId={roomId}
                inviteCode={inviteCode}
                expectedGameType="OMOK"
                onReady={setToken}
            />
        )
    }

    const myTurn = status === "IN_PROGRESS" && turnParticipantId === selfParticipantId
    // 서버가 준 마감시각을 그대로 보여 준다. 카운트다운으로 만들지 않는 이유는 서버가 아직
    // 이 제한시간을 강제하지 않기 때문이다(CLAUDE.md 의 known-gap G1) — 0 에 닿아도 아무 일도
    // 일어나지 않는 카운트다운은 거짓말이 된다.
    const turnHint = turnDeadline ? ` · 제한 ${new Date(turnDeadline).toLocaleTimeString()}` : ""

    return (
        <main className="mx-auto flex w-full max-w-7xl flex-col gap-6 px-4 py-6 lg:flex-row lg:items-start">
            <div className="flex min-w-0 flex-1 flex-col items-center gap-3">
                <OmokBoard
                    size={BOARD_SIZE}
                    placements={placements}
                    disabled={!myTurn}
                    onPlace={(x, y) => socketRef.current?.send("OMOK_PLACE", { x, y })}
                />
                <p className="h-5 text-sm text-muted-foreground">
                    {notice ??
                        (status === "IN_PROGRESS"
                            ? `${myTurn ? "내 차례" : "상대 차례"}${turnHint}`
                            : "")}
                </p>
            </div>

            <RoomSidebar
                participants={participants}
                hostParticipantId={hostParticipantId}
                status={status}
                inviteUrl={inviteUrl}
                selfParticipantId={selfParticipantId}
                onReadyToggle={(ready) => socketRef.current?.send("READY", { ready })}
                onStart={() => socketRef.current?.send("START")}
            />
        </main>
    )
}
```

### Task 9: Dodge tick loop ported to TypeScript

This is the port the replay viewer re-runs. It must match the server exactly, so it gets its own tests.

- Modify: `front/package.json`

**Interfaces:**
- Consumes: nothing.
- Produces:

  - `DODGE_RULES` mirroring the server constants

```ts
/**
 * 서버(app-webflux)의 DodgeGame 을 그대로 옮긴 것이다.
 * 기보 재생은 이 포트가 서버와 한 글자도 다르지 않아야 성립한다 — 바꿀 때는 양쪽을 같이 바꾼다.
 */

export const DODGE_RULES = {
    cols: 12,
    rows: 16,
    tickMs: 100,
    baseSpawn: 0.15,
    spawnStep: 0.05,
    spawnStepTicks: 100,
    maxSpawn: 0.6,
} as const

export interface Cell {
    x: number
    y: number
}

export type DirectionName = "UP" | "DOWN" | "LEFT" | "RIGHT"

const DELTAS: Record<DirectionName, Cell> = {
    UP: { x: 0, y: -1 },
    DOWN: { x: 0, y: 1 },
    LEFT: { x: -1, y: 0 },
    RIGHT: { x: 1, y: 0 },
}

export function xorshift32(seed: number) {
    let state = seed === 0 ? 1 : seed | 0

    const nextInt = () => {
        state ^= state << 13
        state |= 0
        state ^= state >>> 17
        state ^= state << 5
        state |= 0
        return state >>> 0
    }

    return {
        nextInt,
        nextDouble: () => nextInt() / 4294967296,
    }
}

export function spawnProbability(tick: number): number {
    const raised = DODGE_RULES.baseSpawn + DODGE_RULES.spawnStep * Math.floor(tick / DODGE_RULES.spawnStepTicks)
    return Math.min(raised, DODGE_RULES.maxSpawn)
}

export function startingCells(playerCount: number): Cell[] {
    const y = DODGE_RULES.rows - 1
    return Array.from({ length: playerCount }, (_, i) => {
        // 서버의 DodgeRules.startingCells 와 **같은 식**이어야 한다:
        //   round((i + 0.5) * COLUMNS / playerCount - 0.5), 그리고 [0, cols-1] 로 클램프.
        // Java 의 Math.round 와 JS 의 Math.round 는 둘 다 .5 를 +∞ 쪽으로 올리므로 그대로 옮겨진다.
        // floor(i * cols / playerCount) 로 쓰면 8인 게임이 [0,1,3,4,6,7,9,10] 이 되어
        // 서버의 [0,2,3,5,6,8,9,11] 과 **틱 1부터** 갈린다 — 재생이 통째로 다른 게임이 된다.
        const x = Math.round(((i + 0.5) * DODGE_RULES.cols) / playerCount - 0.5)
        return { x: Math.min(Math.max(x, 0), DODGE_RULES.cols - 1), y }
    })
}

export interface DodgeFrame {
    tick: number
    positions: Record<string, Cell>
    obstacles: Cell[]
    eliminatedThisTick: string[]
    finished: boolean
}

export function createDodgeGame(participantIds: string[], seed: number) {
    const random = xorshift32(seed)
    const positions = new Map<string, Cell>()
    const eliminationOrder: string[][] = []

    startingCells(participantIds.length).forEach((cell, index) => {
        positions.set(participantIds[index], cell)
    })

    let obstacles: Cell[] = []
    let tick = 0
    let finished = false
    let spawning = true

    const frame = (eliminated: string[]): DodgeFrame => ({
        tick,
        positions: Object.fromEntries(positions),
        obstacles: [...obstacles],
        eliminatedThisTick: eliminated,
        finished,
    })

    const advanceOneTick = (inputs: Record<string, DirectionName | undefined>): DodgeFrame => {
        if (finished) {
            return frame([])
        }

        const previous = new Map(positions)

        for (const [participantId, name] of Object.entries(inputs)) {
            const current = positions.get(participantId)
            const delta = name ? DELTAS[name] : undefined
            if (!current || !delta) {
                continue
            }
            const x = current.x + delta.x
            const y = current.y + delta.y
            if (x < 0 || x >= DODGE_RULES.cols || y < 0 || y >= DODGE_RULES.rows) {
                continue
            }
            positions.set(participantId, { x, y })
        }

        const fallen: Cell[] = []
        for (const obstacle of obstacles) {
            const y = obstacle.y + 1
            if (y < DODGE_RULES.rows) {
                fallen.push({ x: obstacle.x, y })
            }
        }

        if (spawning) {
            const probability = spawnProbability(tick)
            // 열 0 부터 오름차순. 순회 순서가 난수열의 일부다.
            for (let x = 0; x < DODGE_RULES.cols; x++) {
                if (random.nextDouble() < probability) {
                    fallen.push({ x, y: 0 })
                }
            }
        }

        obstacles = fallen

        const eliminated: string[] = []
        for (const [participantId, now] of positions) {
            const before = previous.get(participantId)
            const hit = obstacles.some((obstacle) => {
                if (obstacle.x === now.x && obstacle.y === now.y) {
                    return true
                }
                // 스왑: 서로 지나쳤다면 겹치지 않아도 부딪힌 것이다.
                return (
                    before !== undefined &&
                    obstacle.x === now.x &&
                    obstacle.y - 1 === now.y &&
                    obstacle.x === before.x &&
                    obstacle.y === before.y
                )
            })
            if (hit) {
                eliminated.push(participantId)
            }
        }

        eliminated.forEach((participantId) => positions.delete(participantId))
        if (eliminated.length > 0) {
            eliminationOrder.push([...eliminated])
        }

        tick += 1
        // 서버(DodgeGame:130)와 같은 조건이다. 아무도 안 남으면 무조건 끝이지만, "한 명 남음"이
        // 종료인 것은 원래 둘 이상으로 시작한 게임에서만이다 — 1인 게임은 시작부터 한 명이므로
        // 그 한 명이 맞을 때까지 계속된다. `positions.size <= 1` 만 보면 1인 기보가 틱 1에서
        // 끝나 버려 서버와 길이가 달라진다.
        if (positions.size === 0 || (participantIds.length > 1 && positions.size <= 1)) {
            finished = true
        }

        return frame(eliminated)
    }

    // 이탈. 입력 스트림 밖에서 상태를 바꾸는 사건이라 v2 기보의 departures 가 이걸 재현한다.
    // 서버 DodgeGame.eliminate 와 한 줄씩 대응한다: 이미 끝났거나 그 참가자가 이미 없으면
    // 아무 일도 하지 않는 멱등 연산이고, 그렇지 않으면 그 틱의 탈락자 버킷을 하나 쌓는다.
    // 여기서는 `positions.size <= 1` 만 본다 — 서버와 같다. 1인 게임에서 그 한 명이 이탈하면
    // positions 가 비므로 이 조건으로도 끝난다.
    const eliminate = (participantId: string) => {
        if (finished || !positions.delete(participantId)) {
            return
        }
        eliminationOrder.push([participantId])
        if (positions.size <= 1) {
            finished = true
        }
    }

    const finalRanks = (): Record<string, number> => {
        const ranks: Record<string, number> = {}
        const alive = [...positions.keys()]
        let nextRank = 1

        if (alive.length > 0) {
            alive.forEach((id) => {
                ranks[id] = 1
            })
            nextRank = 1 + alive.length
        }

        for (let i = eliminationOrder.length - 1; i >= 0; i--) {
            const bucket = eliminationOrder[i]
            bucket.forEach((id) => {
                ranks[id] = nextRank
            })
            nextRank += bucket.length
        }

        participantIds.forEach((id) => {
            if (ranks[id] === undefined) {
                ranks[id] = participantIds.length
            }
        })
        return ranks
    }

    return {
        get tick() {
            return tick
        },
        get finished() {
            return finished
        },
        advanceOneTick,
        eliminate,
        finalRanks,
        disableSpawning: () => {
            spawning = false
        },
        forcePosition: (participantId: string, cell: Cell) => positions.set(participantId, cell),
        forceObstacles: (cells: Cell[]) => {
            obstacles = [...cells]
        },
    }
}

export interface DodgeReplayData {
    seed: number
    participantIds: string[]
    inputsByTick: Record<number, Record<string, DirectionName>>
    // v2. 이탈은 입력이 아니라 상태를 직접 바꾸는 사건이라, 없으면 떠난 참가자가 재생에서
    // 계속 살아 피하고 있게 되어 승자와 길이가 원본과 달라진다.
    departuresByTick: Record<number, string[]>
}

/** 서버 DodgeReplayRunner.MAX_TICKS 와 같은 값. 손상된 기보가 무한 루프에 빠지는 것만 막는다. */
export const REPLAY_MAX_TICKS = 100_000

export type DodgeGameInstance = ReturnType<typeof createDodgeGame>

/**
 * 기보 재생의 **한 틱**. 재생 경로가 둘(테스트용 `rerunReplay`, 화면용 뷰어)이라 이 한 스텝을
 * 두 군데에 각각 적으면 반드시 갈라진다 — 실제로 v2 로 올릴 때 `rerunReplay` 에만 departures 를
 * 넣고 뷰어는 inputsByTick 만 도는 상태로 남았고, 그러면 정작 **사람이 보는 화면**이 v2 가 막으려던
 * 바로 그 틀린 게임을 그린다. 그래서 스텝은 여기 하나뿐이고 둘 다 이걸 부른다.
 *
 * <p>순서가 규칙이다: 그 틱의 이탈을 먼저 기록된 순서대로 반영하고, 그 이탈이 게임을 끝냈으면
 * `advanceOneTick` 은 건너뛴다 — 원본에서도 끝난 게임의 그 호출은 no-op 이었으므로 그래야 틱
 * 수가 정확히 같다. 그 경우 `null` 을 돌려준다(= "이 틱은 진행되지 않았다").
 */
export function stepReplay(game: DodgeGameInstance, replay: DodgeReplayData): DodgeFrame | null {
    const currentTick = game.tick

    for (const participantId of replay.departuresByTick[currentTick] ?? []) {
        game.eliminate(participantId)
    }
    if (game.finished) {
        return null
    }

    return game.advanceOneTick(replay.inputsByTick[currentTick] ?? {})
}

export function rerunReplay(replay: DodgeReplayData) {
    const game = createDodgeGame(replay.participantIds, replay.seed)

    while (!game.finished && game.tick < REPLAY_MAX_TICKS) {
        if (stepReplay(game, replay) === null) {
            break
        }
    }

    // 서버 DodgeReplayRunner:59 와 같은 태도다. 조용히 안 끝난 게임을 돌려주면 finished 를
    // 확인하지 않은 호출자가 손상된/무한한 기보를 "짧은 정상 게임"으로 취급한다.
    if (!game.finished) {
        throw new Error(
            `Dodge replay for seed ${replay.seed} did not finish within ${REPLAY_MAX_TICKS} ticks` +
                " — likely a malformed or non-terminating replay"
        )
    }

    return game
}

/**
 * 헤더가 싣고 있는 규칙 값들. 서버(DodgeReplayWriter)가 이걸 굳이 파일에 쓰는 이유는 클라이언트가
 * 자기 상수와 대조하라는 뜻이다 — 서버 상수가 바뀐 채 저장된 옛 기보를 새 상수로 재생하면 예외도
 * 경고도 없이 다른 게임이 그려진다. 그래서 `v` 와 같은 태도로 즉시 던진다.
 */
const HEADER_RULES: ReadonlyArray<[string, number]> = [
    ["cols", DODGE_RULES.cols],
    ["rows", DODGE_RULES.rows],
    ["tickMs", DODGE_RULES.tickMs],
    ["baseSpawn", DODGE_RULES.baseSpawn],
    ["spawnStep", DODGE_RULES.spawnStep],
    ["spawnStepTicks", DODGE_RULES.spawnStepTicks],
    ["maxSpawn", DODGE_RULES.maxSpawn],
]

export function parseReplayNdjson(text: string): DodgeReplayData {
    const lines = text.trim().split("\n")
    const header = JSON.parse(lines[0])
    if (header.v !== 2) {
        throw new Error(`Unsupported dodge replay version ${header.v}; this reader needs v2`)
    }
    if (header.prng !== "xorshift32") {
        throw new Error(`Unsupported dodge replay prng ${header.prng}; this reader implements xorshift32`)
    }
    for (const [field, expected] of HEADER_RULES) {
        if (header[field] !== expected) {
            throw new Error(
                `Dodge replay header ${field}=${header[field]} does not match this client's ${expected};` +
                    " the two engines would diverge, so refuse to replay it"
            )
        }
    }
    const inputsByTick: Record<number, Record<string, DirectionName>> = {}
    const departuresByTick: Record<number, string[]> = {}

    for (let i = 1; i < lines.length; i++) {
        const line = JSON.parse(lines[i])
        if (line.moves) {
            inputsByTick[line.tick] = line.moves
        }
        if (line.departures) {
            departuresByTick[line.tick] = line.departures
        }
    }

    return {
        seed: header.seed,
        participantIds: (header.players ?? []).map((p: any) => p.participantId),
        inputsByTick,
        departuresByTick,
    }
}
```

```tsx
export default function DodgeRoomPage() {

    const searchParams = useSearchParams()
    const roomId = params.roomId
    const inviteCode = searchParams.get("invite") ?? ""

    const [token, setToken] = useState<string | null>(null)
    const [participants, setParticipants] = useState<ParticipantView[]>([])
    const [hostParticipantId, setHostParticipantId] = useState("")
    const [status, setStatus] = useState<RoomStatus>("WAITING")
    const [tick, setTick] = useState(0)
    const [positions, setPositions] = useState<{ participantId: string; x: number; y: number }[]>([])
    const [obstacles, setObstacles] = useState<{ x: number; y: number }[]>([])
    const [selfParticipantId, setSelfParticipantId] = useState<string | null>(null)
    const [notice, setNotice] = useState<string | null>(null)

    const socketRef = useRef<GameSocket | null>(null)

    const inviteUrl = useMemo(() => {
        if (typeof window === "undefined") {
            return ""
        }
        return `${window.location.origin}/game/dodge/${roomId}?invite=${inviteCode}`
    }, [roomId, inviteCode])

    // payload 는 unknown 이다. isServerMessage 로 좁히는 것이 그것을 읽는 유일한 방법이다 —
    // switch (message.type) 로는 좁혀지지 않는다(아래 노트 참조).
    const handleMessage = useCallback((message: ServerMessage) => {
        if (isServerMessage(message, "ROOM_STATE")) {
            setParticipants(message.payload.participants)
            setHostParticipantId(message.payload.hostParticipantId)
            setStatus(message.payload.status)
            return
        }

            setStatus("IN_PROGRESS")
            setNotice(null)
            return
        }

        return (

                roomId={roomId}
                inviteCode={inviteCode}
                expectedGameType="DODGE"
                onReady={setToken}
            />
        )
    }

    const nameOf = new Map(participants.map((p) => [p.participantId, p.displayName]))
    const players: GridPlayer[] = positions.map((position) => ({
        participantId: position.participantId,
        displayName: nameOf.get(position.participantId) ?? position.participantId,
        x: position.x,
        y: position.y,
        isSelf: position.participantId === selfParticipantId,
    }))

    return (
        <main className="mx-auto flex w-full max-w-7xl flex-col gap-6 px-4 py-6 lg:flex-row lg:items-start">
            <div className="flex min-w-0 flex-1 flex-col items-center gap-3">
                <DodgeGrid players={players} obstacles={obstacles} />
                <p className="h-5 text-sm text-muted-foreground">
                    {notice ?? (status === "IN_PROGRESS" ? `방향키 또는 WASD 로 이동 · ${tick}틱` : "")}
                </p>
            </div>

            <RoomSidebar
                participants={participants}
                hostParticipantId={hostParticipantId}
                status={status}
                inviteUrl={inviteUrl}
                selfParticipantId={selfParticipantId}
                onReadyToggle={(ready) => socketRef.current?.send("READY", { ready })}
                onStart={() => socketRef.current?.send("START")}
            />
```

```tsx
"use client"

import { useEffect, useMemo, useState } from "react"
import { Loader2, Pause, Play, SkipBack, SkipForward } from "lucide-react"
import { Button } from "@/components/ui/button"
import DodgeGrid, { type GridPlayer } from "@/components/game/dodge-grid"
import OmokBoard, { type OmokPlacement } from "@/components/game/omok-board"
import {
    DODGE_RULES,
    REPLAY_MAX_TICKS,
    createDodgeGame,
    parseReplayNdjson,
    stepReplay,
} from "@/lib/dodge-engine"
import type { GameType } from "@/lib/types"

interface ReplayViewerProps {
    gameType: GameType
    replayUrl: string
    onClose: () => void
}

interface DodgeSnapshot {
    positions: { participantId: string; x: number; y: number }[]
    obstacles: { x: number; y: number }[]
}

export default function ReplayViewer({ gameType, replayUrl, onClose }: ReplayViewerProps) {
    const [text, setText] = useState<string | null>(null)
    const [error, setError] = useState<string | null>(null)
    const [frameIndex, setFrameIndex] = useState(0)
    const [playing, setPlaying] = useState(false)

    useEffect(() => {
        fetch(replayUrl)
            .then((response) => {
                if (!response.ok) {
                    throw new Error("기보를 내려받지 못했습니다.")
                }
                return response.text()
            })
            .then(setText)
            .catch((cause) => setError(cause instanceof Error ? cause.message : "기보를 읽지 못했습니다."))
    }, [replayUrl])

    const omokMoves: OmokPlacement[] = useMemo(() => {
        if (gameType !== "OMOK" || !text) {
            return []
        }
        const lines = text.trim().split("\n")
        const header = JSON.parse(lines[0])
        const colorOf = new Map<string, "BLACK" | "WHITE">(
            (header.players ?? []).map((p: any) => [p.participantId, p.color])
        )
        return lines.slice(1).map((line) => {
            const move = JSON.parse(line)
            return { x: move.x, y: move.y, color: colorOf.get(move.p) ?? "BLACK" }
        })
    }, [gameType, text])

    // 장애물피하기는 시드와 입력과 **이탈**로 서버와 같은 틱 로직을 다시 돌린다.
    // 한 틱을 진행하는 코드는 여기 따로 적지 않고 dodge-engine 의 stepReplay 를 부른다 —
    // rerunReplay(테스트용)와 이 화면(사람이 실제로 보는 것)이 각자 다른 스텝을 갖는 순간
    // 화면 쪽만 조용히 틀리게 되고, v2 는 정확히 그 사고를 막으려고 올린 버전이다.
    const dodgeFrames: DodgeSnapshot[] = useMemo(() => {
        if (gameType !== "DODGE" || !text) {
            return []
        }
        const replay = parseReplayNdjson(text)
        const game = createDodgeGame(replay.participantIds, replay.seed)
        const frames: DodgeSnapshot[] = []

        while (!game.finished && game.tick < REPLAY_MAX_TICKS) {
            const frame = stepReplay(game, replay)
            if (frame === null) {
                break
            }
            frames.push({
                positions: Object.entries(frame.positions).map(([participantId, cell]) => ({
                    participantId,
                    x: cell.x,
                    y: cell.y,
                })),
                obstacles: frame.obstacles,
            })
        }
        return frames
    }, [gameType, text])

    const totalFrames = gameType === "OMOK" ? omokMoves.length : dodgeFrames.length

    useEffect(() => {
        if (!playing || frameIndex >= totalFrames) {
            return
        }
        const delay = gameType === "DODGE" ? DODGE_RULES.tickMs : 500
        const timer = window.setTimeout(() => setFrameIndex((index) => index + 1), delay)
        return () => window.clearTimeout(timer)
    }, [playing, frameIndex, totalFrames, gameType])

    if (error) {
        return (
            <div className="space-y-3 rounded-lg border p-6">
                <p className="text-sm text-destructive">{error}</p>
                <Button variant="outline" onClick={onClose}>
                    닫기
                </Button>
            </div>
        )
    }

    if (!text) {
        return (
            <div className="flex items-center justify-center rounded-lg border p-10">
                <Loader2 className="h-5 w-5 animate-spin text-muted-foreground" />
            </div>
        )
    }

    const dodgeFrame = dodgeFrames[Math.min(frameIndex, dodgeFrames.length - 1)]
    const dodgePlayers: GridPlayer[] = (dodgeFrame?.positions ?? []).map((position) => ({
        participantId: position.participantId,
        displayName: position.participantId,
        x: position.x,
        y: position.y,
        isSelf: false,
    }))

    return (
        <div className="space-y-4 rounded-lg border p-6">
            <div className="flex justify-center">
                {gameType === "OMOK" ? (
                    <OmokBoard size={15} placements={omokMoves.slice(0, frameIndex)} disabled onPlace={() => {}} />
                ) : (
                    <DodgeGrid players={dodgePlayers} obstacles={dodgeFrame?.obstacles ?? []} />
                )}
            </div>

            <div className="flex items-center justify-center gap-2">
                <Button size="icon" variant="outline" onClick={() => setFrameIndex(0)} aria-label="처음으로">
                    <SkipBack className="h-4 w-4" />
                </Button>
                <Button size="icon" variant="outline" onClick={() => setPlaying((value) => !value)}
                    aria-label={playing ? "일시정지" : "재생"}>
                    {playing ? <Pause className="h-4 w-4" /> : <Play className="h-4 w-4" />}
                </Button>
                <Button size="icon" variant="outline" onClick={() => setFrameIndex(totalFrames)} aria-label="끝으로">
                    <SkipForward className="h-4 w-4" />
                </Button>
                <span className="ml-2 text-xs text-muted-foreground">
                    {Math.min(frameIndex, totalFrames)} / {totalFrames}
                </span>
                <Button variant="ghost" className="ml-4" onClick={onClose}>
                    닫기
                </Button>
            </div>
        </div>
    )
}
```

```tsx
"use client"

import { useEffect, useState } from "react"
import { useRouter } from "next/navigation"
import Image from "next/image"
import { Loader2 } from "lucide-react"
import { Button } from "@/components/ui/button"
import ReplayViewer from "@/components/game/replay-viewer"
import { authAPI, gameAPI } from "@/lib/api"
import { useAuth } from "@/hooks/use-auth"
import type { GameResultSummary, GameType, MemberProfile } from "@/lib/types"

export default function MyPage() {
    const router = useRouter()
    const { loading, isAuthenticated } = useAuth()

    const [profile, setProfile] = useState<MemberProfile | null>(null)
    const [results, setResults] = useState<GameResultSummary[]>([])
    const [error, setError] = useState<string | null>(null)
    const [replay, setReplay] = useState<{ gameType: GameType; url: string } | null>(null)

    useEffect(() => {
        if (!loading && !isAuthenticated) {
            router.replace("/login")
        }
    }, [loading, isAuthenticated, router])

    useEffect(() => {
        if (loading || !isAuthenticated) {
            return
        }

        Promise.all([authAPI.me(), gameAPI.myResults()])
            .then(([loadedProfile, loadedResults]) => {
                setProfile(loadedProfile)
                setResults(loadedResults)
            })
            .catch((cause) => setError(cause instanceof Error ? cause.message : "불러오지 못했습니다."))
    }, [loading, isAuthenticated])

    const openReplay = async (result: GameResultSummary) => {
        try {
            const url = await gameAPI.replayUrl(result.gameResultId)
            setReplay({ gameType: result.gameType, url })
        } catch (cause) {
            setError(cause instanceof Error ? cause.message : "기보를 불러오지 못했습니다.")
        }
    }

    if (loading || (!profile && !error)) {
        return (
            <div className="flex min-h-[50vh] items-center justify-center">
                <Loader2 className="h-6 w-6 animate-spin text-muted-foreground" />
            </div>
        )
    }

    return (
        <main className="mx-auto w-full max-w-3xl space-y-10 px-4 py-10">
            <section className="space-y-4">
                <h1 className="text-2xl font-semibold">마이페이지</h1>
                {error ? <p className="text-sm text-destructive">{error}</p> : null}

                {profile ? (
                    <div className="flex items-center gap-4 rounded-lg border p-5">
                        <div className="relative h-16 w-16 shrink-0 overflow-hidden rounded-full bg-muted">
                            {profile.profileImageUrl ? (
                                <Image
                                    src={profile.profileImageUrl}
                                    alt={profile.nickname}
                                    fill
                                    unoptimized
                                    className="object-cover"
                                />
                            ) : null}
                        </div>
                        <div className="min-w-0">
                            <p className="truncate text-lg font-medium">{profile.nickname}</p>
                            <p className="truncate text-sm text-muted-foreground">{profile.email}</p>
                            <p className="mt-1 text-sm">게임 머니 {profile.gameMoney.toLocaleString()}</p>
                        </div>
                    </div>
                ) : null}
            </section>

            <section className="space-y-4">
                <h2 className="text-lg font-medium">전적</h2>

                {results.length === 0 ? (
                    <p className="text-sm text-muted-foreground">아직 끝낸 게임이 없습니다.</p>
                ) : (
                    <ul className="space-y-2">
                        {results.map((result) => (
                            <li
                                key={result.gameResultId}
                                className="flex items-center justify-between gap-3 rounded-md border px-4 py-3 text-sm"
                            >
                                <div className="min-w-0">
                                    <p className="font-medium">
                                        {result.gameType === "OMOK" ? "오목" : "장애물피하기"} · {result.finishRank}위
                                    </p>
                                    <p className="truncate text-xs text-muted-foreground">
                                        {result.endedAt} · 승자 {result.winnerDisplayName || "-"}
                                    </p>
                                </div>
                                <Button
                                    size="sm"
                                    variant="outline"
                                    disabled={!result.replayAvailable}
                                    onClick={() => openReplay(result)}
                                >
                                    다시보기
                                </Button>
                            </li>
                        ))}
                    </ul>
                )}
            </section>

            {replay ? (
                <section className="space-y-3">
                    <h2 className="text-lg font-medium">기보 다시보기</h2>
                    <ReplayViewer
                        gameType={replay.gameType}
                        replayUrl={replay.url}
                        onClose={() => setReplay(null)}
                    />
                </section>
            ) : null}
        </main>
    )
}
```
