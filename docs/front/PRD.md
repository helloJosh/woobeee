# PRD — front (프론트엔드)

`front`는 백엔드 API를 사용해 사용자 화면을 제공하는 Next.js 14 애플리케이션이다. 이 문서는 화면이 제공해야 할 **제품 목표·사용자 여정·범위**를 정의한다. 디렉터리 구조, API 호출/토큰 규칙, 스타일·컴포넌트 규칙 등 구현 기준은 [`../FRONTEND.md`](../FRONTEND.md)에 있다.

- 코드: `front/`
- 전역 맥락: [`../_global/PRD.md`](../_global/PRD.md)

## 목표

- 방문자가 랜딩에서 게임과 기술블로그로 갈라져 들어간다.
- 회원이 게임 방을 만들고, 초대 링크로 부른 친구가 **로그인 없이 닉네임만으로** 같은 방에서 논다.
- 오목과 장애물피하기를 실시간으로 플레이한다.
- 회원이 자기 프로필과 전적을 보고, 끝난 게임의 기보를 다시 본다.
- 사용자가 Google 인증으로 가입·로그인하고, 로그인 뒤 **원래 가려던 곳으로 돌아온다**.

## 상단탭

세 개다: 홈(`/`) / 기술블로그(`/blog`) / 마이페이지(`/mypage`). 게임은 탭이 아니라 홈 랜딩의
CTA 로 들어간다 — 초대 링크로 오는 사람이 대부분이라 탭 하나를 상시 차지할 이유가 없다.
헤더는 루트 레이아웃에서 마운트되므로 모든 라우트에 나온다.

## 사용자 여정

### 인증
- 로그인/회원가입 시작 화면에서 백엔드의 시작 API로 `authorizationUrl`과 `state`를 받아 Google로 이동한다.
- `/auth/google/callback`에서 `code`/`state`를 `POST /api/auth/callback-google`로 교환해 토큰을 받는다(Authorization Code + PKCE).
- **로그인 뒤에는 원래 가려던 곳으로 돌아간다.** 초대 링크를 열었다가 로그인이 필요해진 사람을
  홈에 버려두면 방까지 다시 걸어와야 한다. 같은 탭 안에서 끝나는 경로는 `?next=`로, Google 왕복은
  OAuth `state`를 키로 한 `sessionStorage` 항목으로 목적지를 나른다. 돌아갈 곳이 없으면 홈(`/`).
- `next` 값은 사용자가 고쳐 쓸 수 있는 URL에서 오므로 반드시 살균한다. 통과 조건은 같은 오리진의
  절대 경로 하나이고, 거절한 것은 전부 홈으로 떨군다.

### 게임 메인 (`/game`)
- 오목·장애물피하기 카드를 보여주고 각각 **방 만들기**를 제공한다.
- 방 만들기는 회원만 가능하다. 비로그인 상태에서 누르면 `/game`으로 돌아오는 `next`를 달아
  로그인으로 보낸다.
- 방을 만들면 곧바로 그 방의 플레이 화면(`/game/<게임>/<roomId>?invite=<code>`)으로 이동한다.

### 방 참가 (초대 링크)
- 초대 링크를 열면 참가 게이트가 먼저 뜬다. 방 요약(게임 종류·인원)을 보여주고 두 갈래로 나뉜다.
  - 회원: 액세스 토큰으로 바로 들어간다.
  - 비회원: 닉네임을 입력해 게스트 토큰을 발급받는다(trim 후 1~20자 — 앞뒤 공백만 제외하고
    내부 공백은 길이에 포함된다). 로그인 링크도 함께 준다.
- 정원이 찼거나 이미 시작된 방은 들어가기 전에 이유를 알려주고 막는다.
- 발급받은 게스트 토큰은 탭 단위로 보관해 **새로고침해도 같은 자리로 돌아간다**. 서버가 참가를
  거절하면 그 토큰을 버려 닉네임 폼으로 되돌아갈 수 있게 한다.

### 방과 플레이
- 두 게임 화면은 같은 사이드바를 공유한다: 참가자 명단(방장 표시·준비 상태·연결 끊김 표시),
  초대 링크 복사, 준비 토글, 방장의 게임 시작 버튼.
- 시작 조건(2명 이상 전원 준비)을 화면이 미리 보여주지만 최종 판정은 서버다 — 버튼이 활성화돼도
  서버가 거절할 수 있고 그건 정상이다.
- **오목**: 15×15 판. 내 차례에만 둘 수 있고, 흑의 금수는 한국어 사유로 거절 안내가 뜨되 판은
  바뀌지 않는다. 거절 안내는 **내가 둔 수에 대해서만** 보여준다(서버는 방 전체에 뿌린다).
  직전 착수를 표시해 225칸 위에서 상대 수를 찾을 수 있게 한다.
- **장애물피하기**: 36×48 서브칸 격자(화면상 12×16 칸 체감). 방향키/WASD 로 움직인다. 참가자는 색과 번호로 구분하고,
  배정 순서는 도중 이탈이 있어도 **밀리지 않는다**. 탈락하면 입력을 막고 관전으로 남는다.
- 끊겼다 돌아오면 서버가 현재 판을 통째로 보내 주므로 화면이 그대로 이어진다.
- 게임이 끝나면 순위와 승자를 보여준다.

### 마이페이지 (`/mypage`)
- 회원 전용이다. 비로그인이면 여기로 돌아오는 `next`를 달아 로그인으로 보낸다.
- 프로필(닉네임·이메일·게임머니·프로필 이미지)을 **표시**한다. 업로드 화면은 아직 없다.
- 전적을 최신순으로 나열하고 더 보기로 이어 받는다. 각 항목은 게임 종류·종료 시각·내 순위·승자.
- 기보가 있는 항목은 **다시보기**를 연다. 재생/일시정지, 앞뒤 한 수(틱) 이동, 위치 표시를 제공하고
  내 말은 따로 표시한다. 오목은 착수를 되짚고, 장애물피하기는 시드와 입력으로 판을 다시 돌린다.
- 기보를 읽지 못하면(형식·버전 불일치) 조용히 다른 게임을 그리지 않고 실패를 알린다.

### 블로그
- `/blog` 목록, `/blog/[postId]` 상세를 제공한다.
- 헤더의 카테고리 사이드바 토글과 검색창은 이 화면이 등록할 때만 나온다.
- 요청에 언어 정보(`ko-KR`/`en-US`)를 포함해 다국어 콘텐츠를 표시한다([`../blog/adr/ADR-002-i18n.md`](../blog/adr/ADR-002-i18n.md)).

## 인증 상태 처리

- access/refresh token, `memberId`, `role`을 `localStorage`에 저장한다.
- 인증 만료 시 `POST /api/auth/refresh-tokens`로 재발급을 시도하고, 실패하면 토큰을 제거한다.
- **게임 화면의 배경 신원 확인(`GET /api/game/me`)만 이 전역 처리에서 뺀다.** 게스트 토큰으로
  멀쩡히 두고 있는 판이 액세스 토큰 만료 하나로 끝나면 안 된다.
- 역할은 `ROLE_MEMBER` 하나뿐이라 역할 기반 UI 분기는 없다([`../auth/adr/ADR-003-member.md`](../auth/adr/ADR-003-member.md)).

## 범위와 제약

- 현재 화면 범위: 랜딩, 게임 메인·방 참가·오목·장애물피하기, 마이페이지(프로필·전적·기보),
  블로그 목록/상세, 로그인·회원가입·로그아웃, Google callback.
- **폐기 화면**: `app/products`, `app/cart`, `app/chat` 은 폐기된 product/cart 백엔드를 호출한다.
  살아 있는 화면(랜딩 등)에서 이 세 경로로 들어가는 진입 링크는 걷어냈다. 다만 폐기 화면끼리는
  아직 서로 링크한다 — `app/products/[productId]/page.tsx` 의 상단 바가 여전히 `/cart` 로
  가는 링크를 그린다. 페이지 삭제는 후속 과제다.
- 미구현: 프로필 이미지 업로드 UI(표시만 한다).
- 다크/라이트 모드 전환(`next-themes`)을 제공한다.
- WebSocket 은 Next rewrites 를 타지 못해 브라우저가 WebFlux 오리진에 직접 붙는다 —
  `NEXT_PUBLIC_WS_BASE_URL` 이 필요하다.
- 검증은 `cd front && npm test && npm run build`. `next/font`의 Google Fonts 조회로 네트워크 차단
  시 빌드가 실패할 수 있다.

## 비기능 요구사항

- API 응답은 백엔드의 `ApiResponse` 규약(`header.isSuccessful`/`message`)을 기준으로 성공/실패를 처리한다([`../_common/adr/ADR-002-apiresponse.md`](../_common/adr/ADR-002-apiresponse.md)).
- 게임 API 의 실패는 `header.message` 에 실린 `game_*` 코드를 사용자 문구로 옮겨 **인라인 배너**로
  보여준다. blocking `alert()` 은 쓰지 않는다 — 판이 도는 중에 뜨면 조작을 막는다.
- 공통 호출 로직은 `lib/api.ts`, 타입은 `lib/types.ts`로 모은다.
- **화면 상태를 정하는 판단은 컴포넌트가 아니라 `lib/` 의 React-free 모듈에 두고 테스트로 고정한다.**
  근거와 목록은 [`../FRONTEND.md`](../FRONTEND.md).
- UI는 `components/ui/`의 기존 컴포넌트를 우선 재사용한다.
